# Security policy

This repository is an experimental demonstration, not a production-supported service. No supported release or response-time guarantee has been established.

## Reporting a vulnerability

Use GitHub private vulnerability reporting if enabled in the repository Security tab. If unavailable, request a private reporting channel through a public issue without including vulnerability details, credentials or personal data. Do not publish exploit details before coordination with the maintainer.

Include affected revision, impact and safe reproduction steps using synthetic data. Test only systems you own or are authorized to test.

## Deployment precautions

Run the pipeline in an isolated workspace with authorized input data. Treat generated files and databases as potentially sensitive; do not expose them publicly.
